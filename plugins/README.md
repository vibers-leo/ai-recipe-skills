# 수업에서 함께 쓰는 공식 플러그인

| 도구 | 시작할 곳 | 첫 확인 |
|---|---|---|
| plugin-management | Codex의 설정 → 플러그인 → 디렉터리에서 필요한 서비스를 찾는다. | “연결 전에 필요한 권한과 읽기 도구를 알려 줘.” |
| Higgsfield | 디렉터리에서 Higgsfield를 추가하고 본인 계정을 연결한다. [공식 연결 안내](https://higgsfield.ai/creator-hub/help-center/integrations/how-do-i-connect-higgsfield-to-ai-agent) | 새 대화에 “Higgsfield 도구로 잔액만 조회해 줘. 생성·결제는 하지 마.”라고 입력하고 반환값을 본다. 무료 캐릭터 실습은 [웹 Builder](https://higgsfield.ai/ko/ai-influencer-studio)에서 본인 계정의 무료 적용 표시를 확인한다. |
| Sites | Sites를 사용할 수 있는 환경에서 플러그인을 선택하고 소개 문구·메뉴·로고를 준비한다. | “소개 랜딩과 사용하는 홈을 나눈 커뮤니티 시안을 미리보기로 만들어 줘.” |

각 서비스의 계정·권한은 수강생이 사용하는 앱에서 연결한다. 로컬 디자인을 연습할 때는 vibers-design 폴더의 스킬로 먼저 시작할 수 있다.
