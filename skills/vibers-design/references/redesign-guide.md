# Vibers Redesign Workflow

## 리디자인 프로세스

1. **기존 코드 분석** — 섹션 구조, 색상, 폰트, 컴포넌트 파악
2. **테마 선택** — 서비스 성격에 맞는 테마 결정 (또는 사용자 지정)
3. **에이전시 랜딩 참조** — `수강생이 준비한 랜딩 시안` 폴더 레퍼런스 확인
4. **전면 재작성** — 기존 콘텐츠(텍스트, 가격, 기능) 유지 + 디자인 완전 교체
5. **출력** — output-skill 규칙에 따라 완전한 파일 생성

## 테마 선택 기준

| 서비스 유형 | 추천 테마 |
|-----------|---------|
| 행사·축제·에이전시 | DARK_ORANGE |
| 세무·법률·금융·B2B | LIGHT_GREEN |
| 웨딩·초대장·감성 브랜드 | WARM_CREAM |
| 스포츠·러닝·피트니스 | BOLD_DARK |
| SaaS·AI·구독·테크 | SOFT_LIGHT |
| 기본값 (미지정) | MODERN_BW |

## 기존 코드에서 보존할 것
- 모든 텍스트 콘텐츠 (헤드라인, 설명, 가격, 기능 목록)
- 링크 anchor ID (#contact, #packages 등)
- 폼 필드 구조
- 데이터 상수 (PACKAGES, BENEFITS 등)

## 기존 코드에서 교체할 것
- 모든 색상 → 선택된 테마 팔레트
- 모든 폰트 → 테마 폰트 스택
- 레이아웃 → 수파노바/Vibers 레이아웃 규칙
- 인라인 스타일 → 테마 CSS 클래스
- 이모지 → Iconify Solar 아이콘
