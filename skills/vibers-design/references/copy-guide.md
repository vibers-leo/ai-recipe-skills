| LIGHT_GREEN | 신뢰·전문적 | "놀라운", "혁신적" | "검증된", "정확한", "전문가가" |

| SOFT_LIGHT | 미니멀·명확 | "다양한", "여러가지" | 구체적 숫자만, "3분 만에", "무료로" |

## 전체 금지 표현 (모든 테마)
- "혁신적인", "획기적인", "차세대", "스마트한"
- "최고의 서비스를 제공합니다"
- "고객 중심의"
- 번역체: "이것은 당신을 위한 것입니다"

## 숫자 표기
- 유기적 숫자: `847+` not `1,000+` / `47,200+` not `50,000+`
- 한국식: `12년+`, `98.7%`, `24시간 내`
- 가격: `100만원` (띄어쓰기 없이)

## 신뢰 지표 예시 (테마별)

**DARK_ORANGE (행사 에이전시):**
- `14일` 평균 제작 기간
- `47+` 완성된 행사 사이트
- `100%` 모바일 반응형
- `4개` 와요 생태계 자동 연동

**LIGHT_GREEN (전문직/세무):**
- `12년+` 세무 경력
- `847+` 기장 고객사
- `98.7%` 재계약률
- `24h` 세무사 직접 응답

**WARM_CREAM (웨딩/초대장):**
- `2,400+` 제작된 초대장
- `98%` 하객 만족도
- `3D` 봉투 오프닝 애니메이션
- `24h` 내 초안 전달

**BOLD_DARK (스포츠/러닝):**
- `12,000+` 러너 커뮤니티
- `847+` 완주 기록
- `전국 42+` 코스 등록
- `실시간` 페이스 트래킹

**SOFT_LIGHT (SaaS/팬이지):**
- `3분` 페이지 완성
- `무료` 기본 플랜
- `AI` 콘텐츠 자동 생성
- `99.9%` 서비스 가동률

## 섹션 헤드라인 패턴

히어로 헤드라인은 반드시 **2~3줄 구조**:
```
[동사/명사 강조] +
[핵심 가치 or 브랜드명] +
[결과/혜택]
```

예시 (DARK_ORANGE):
```
모든 행사가
시작되는 곳,
마당
```

예시 (LIGHT_GREEN):
```
검증된 세무사가
직접 챙겨드립니다
```

예시 (WARM_CREAM):
```
소중한 순간을
아름답게 전하세요
```
