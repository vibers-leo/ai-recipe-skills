# CTA 패턴 (전환 유도 문구)

버튼·링크·CTA 섹션에서 쓰는 문구 패턴. 목적은 사용자의 다음 행동을 자연스럽게 유도하는 것.

## 핵심 공식

**행동 동사 + (선택) 가치 한 스푼**

행동 동사만 써도 충분하다. 가치를 덧붙이는 건 전환율을 높여야 할 핵심 CTA에만. 모든 버튼에 가치를 붙이면 화면이 무거워지고 신뢰도가 떨어진다.

```
약함 : 확인
중간 : 확인하기
좋음 : 지금 확인하기 (핵심 CTA에만)
나쁨 : ✨ 지금 바로 무료로 확인해보기 🎉 (과함)
```

## 버튼 유형별 패턴

### A. 제출·완료형 버튼 (폼 끝, 주문, 결제)

원본 → 제안

- 제출 → 제출하기 / 보내기
- 확인 → 확인하기
- 저장 → 저장하기
- 완료 → 다 됐어요 / 완료
- 결제하기 → 결제하기 (그대로 OK)
- 주문하기 → 주문하기

**원칙:** 이 유형은 **간결함이 신뢰**다. 과한 수식어는 오히려 의심을 부른다. 결제 단계에서 "✨ 지금 결제하기" 같은 건 오히려 전환율이 떨어진다.

### B. 시작·탐색형 버튼 (홈, 랜딩, 온보딩)

원본 → 제안

- 시작하기 → 시작하기 / 바로 시작하기
- 둘러보기 → 둘러보기 / 먼저 살펴보기
- 가입하기 → 시작하기 (가입이라는 부담 단어를 숨김)
- 회원가입 → 30초면 가입해요 (가치 명시가 효과적인 유일한 경우)
- 무료로 시작 → 무료로 시작하기

**원칙:** 첫 진입 장벽을 낮추는 데 집중. "가입"처럼 부담을 주는 단어는 숨기거나 가치로 바꾼다.

### C. 파괴·위험형 버튼 (삭제, 취소, 탈퇴)

원본 → 제안

- 삭제 → 삭제 (재확인 모달에서 다시 "정말 삭제할까요?")
- 취소 → 취소 / 그만두기
- 탈퇴하기 → 탈퇴하기 (그대로, 꾸미지 말 것)
- 계정 삭제 → 계정 삭제

**원칙:** 위험한 행동일수록 **꾸미면 안 된다**. "없애볼까요?" 같은 친근한 표현은 오히려 사용자가 심각성을 못 느껴서 실수를 유발한다. 다만 재확인 모달의 본문에서는 톤을 부드럽게 할 수 있다.

### D. 보조·선택형 버튼 (건너뛰기, 나중에, 다시 보지 않기)

원본 → 제안

- 건너뛰기 → 건너뛰기 / 나중에 할게요
- 나중에 → 나중에 할게요
- 다시 보지 않기 → 다시 보지 않기
- 닫기 → 닫기

**원칙:** 사용자의 "아니오"를 존중한다. 이 버튼을 숨기거나 작게 만들면 CS 불만이 쌓인다.

## 링크·텍스트 CTA 패턴

본문 안에 섞여 있는 텍스트 CTA는 버튼보다 **더 자연스러워야** 한다.

- 더보기 → 더 보기 / 전체 보기
- 자세히 알아보기 → 자세히 보기
- 바로가기 → 바로 가기
- 여기를 클릭하세요 → 사용 금지 (접근성 문제 + 맥락 부족)

**원칙:** 링크 텍스트만 봐도 어디로 가는지 알 수 있어야 한다. "여기", "클릭"은 절대 쓰지 말 것.

## 빈 버튼 vs. 채운 버튼의 톤

같은 "결제하기"라도 주 버튼(primary)인지 보조 버튼(secondary)인지에 따라 톤이 달라질 수 있다.

- Primary: "결제하기" (단호하게)
- Secondary: "나중에 결제할게요" (선택권을 강조)

## 전환율 관점의 심리 포인트

1. **손실 회피:** "놓치지 마세요"보다 "지금 받아가기"가 낫다. 부정형을 피한다.
2. **즉시성:** "지금", "바로"를 남용하면 광고처럼 느껴진다. 핵심 CTA 1개에만 사용.
3. **구체성:** "시작하기"보다 "30초 만에 시작하기"가 전환율이 높다. 숫자·시간이 있으면 구체성이 생긴다.
4. **부담 제거:** "가입 없이", "무료로", "카드 없이" 같은 장벽 제거 문구는 효과적. 단 남발 금지.

## Before/After 종합 예시

```
케이스 1 — 너무 차가운 CTA
원본: 확인
제안: 확인하기
이유: 버튼 레이블은 동사 원형보다 "~기" 어미가 자연스럽다.

케이스 2 — 부담 주는 가입 CTA
원본: 회원가입 후 이용하기
제안: 30초면 시작해요
이유: "가입"과 "이용"이라는 부담 단어 제거, 가치(소요 시간) 제시.

케이스 3 — 과도하게 꾸민 CTA
원본: ✨ 지금 바로 무료로 신청하고 혜택 받아보기 🎉
제안: 무료로 신청하기
이유: 수식어·이모지 제거. 핵심은 "무료" 한 단어로 충분.

케이스 4 — 모호한 텍스트 링크
원본: 자세한 내용은 여기를 클릭하세요.
제안: 자세한 내용은 이용약관에서 확인해요.
이유: 링크 텍스트만 봐도 목적지가 명확해야 한다.

케이스 5 — 삭제 버튼 꾸미기
원본: 정말 없애볼까요? 😢
제안 (버튼): 삭제하기
제안 (재확인 모달 본문): 이 게시물을 삭제할까요? 삭제하면 복구할 수 없어요.
이유: 위험한 행동은 꾸미면 안 된다. 모달 본문에서 결과(복구 불가)를 명확히 고지.
```
