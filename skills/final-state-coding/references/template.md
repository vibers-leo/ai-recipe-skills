# 최종상태와 검수 작업 양식

- 사용자 원문 / 제품 목적 / 이번 범위와 범위 밖:
- 사용자·관리자·운영자: 상황 → 행동 → 결과 / 실패 시 대응:
- 완료 기준: 조건 | 검증 환경·절차 | 실제 결과·증거 | 미확인
- 확인된 사실 / 가정 / AI 보강 제안과 영향:
- 재사용 후보: 출처·버전 | 실제 검증 수준 | 권리·라이선스 | 고객 데이터·비밀 분리 | 적용 비용·판정
- 대상 형식과 스택 결정 근거 / PG 및 공통 어드민의 실제 상태와 의존성:
- 역산: 사용자 검수·보완 → 통합/권한/실패/결제 테스트 → 구현 → 사전 준비; 담당·기한 근거·의존성·여유·미확정 포함
- 오늘 실행: 우선순위 | 실제 변경 | 검증 및 증거 | 운영 반영 여부 | 다음 행동
- 완성본 검수 패키지: 접근·실행 방법, 역할별 검수 시나리오, 증거, 제약, 운영·복구·인계, 남은 결정.
