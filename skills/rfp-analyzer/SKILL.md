# RFP 분석기

공공기관 공고서·제안요청서(RFP)·과업지시서를 구조적으로 분석한다.

## 지원 문서 유형
- 공고서 (입찰공고, 공모공고)
- 제안요청서 (RFP)
- 과업지시서 (SOW)
- 평가기준표 (배점표, 심사기준)
- 사업설명서

## 분석 프로세스

### Step 1: 문서 입력

| 파일 형식 | 처리 방법 |
|----------|---------|
| `.hwp` / `.hwpx` | `npx tsx tools/hwp-parser/index.ts [경로]` |
| `.pdf` | Read 도구로 직접 읽기 |
| `.md` / `.txt` | Read 도구로 직접 읽기 |
| 텍스트 직접 입력 | 바로 분석 진행 |

### Step 2: 핵심 정보 추출

```markdown
## 사업 기본 정보

| 항목 | 내용 |
|------|------|
| 사업명 | [정식 사업명] |
| 발주 기관 | [기관명] |
| 사업 유형 | [용역/구축/운영/교육/컨설팅] |
| 예산 규모 | [금액 또는 추정] |
| 사업 기간 | [시작일 ~ 종료일] |
| 신청 마감일 | [마감일 + 시간] |
| 제출 방법 | [온라인/오프라인/나라장터] |

## 과업 범위

### 필수 요구사항
1. [요구사항 1]
2. [요구사항 2]

### 선택/권장 요구사항
1. [권장사항 1]

## 평가 기준 및 배점

| 평가 항목 | 배점 | 세부 기준 |
|----------|------|---------|
| [항목1] | [점수] | [기준] |

총점: [점수] / 합격 기준: [기준]

## 제출 서류 목록
- [ ] [서류1]
- [ ] [서류2]

## 자격 요건
- [자격1]
- [자격2]
```

### Step 3: 적합도 분석

우리 회사 역량과 매칭하여 강점/약점 분석:

```markdown
## 적합도 분석

### 강점 (잘할 수 있는 부분)
- ✅ [강점1]: [근거]

### 약점/보완 필요
- ⚠️ [약점1]: [대응 방안]

### 경쟁 우위 포인트
- [차별화 포인트]

### 입찰 참여 권고
- 권고도: ★★★★☆ (5점 만점)
- 예상 경쟁 강도: [높음/보통/낮음]
- 권고 의견: [참여/신중/비추천] — [이유]
```

### Step 4: 제안 전략 수립

```markdown
## 제안서 작성 전략

### 핵심 메시지 (1줄)
"[핵심 차별화 메시지]"

### 강조할 포인트 (배점 기준 우선순위)
1. [배점 높은 항목] → [어필 포인트]
2. [배점 높은 항목] → [어필 포인트]

### 예상 소요 기간
- 분석 → 초안: [일수]
- 초안 → 검토: [일수]
- 검토 → 제출: [일수]
```

## 분석 완료 후

분석 결과를 `proposals/[사업명]/analysis.md`에 저장하고 제안서 작성 여부 확인.
제안서 작성은 `/proposal-writer` 스킬로 이어서 진행.
